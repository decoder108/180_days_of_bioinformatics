**Priyanka Singh**

## About this challenge

A six-month, one-hour-per-day learning and project portfolio. My goal is to connect biological fundamentals with reliable computational methods, critically evaluate research papers, and build transparent, reproducible analyses using public datasets.

**Daily rhythm:** 15 min paper reading · 35 min hands-on work · 10 min documentation and GitHub update. A meaningful update may be code, tests, results, or an annotated paper note.

## Roadmap

| Month | Focus | Projects |
|---|---|---|
| 1 | Genomics, Python and fundamentals | DNA sequence analyzer; variant explorer |
| 2 | Transcriptomics and functional genomics | Differential expression; pathway enrichment |
| 3 | Single-cell and spatial transcriptomics | Cell atlas; spatial analysis |
| 4 | **Biological image analysis** | Microscopy segmentation; bioimage classifier |
| 5 | Clinical genomics and biomedical ML | Variant prioritization; biomarker prediction |
| 6 | Production bioinformatics | Nextflow workflow; packaged CLI |

## Projects

Each project has a clear biological question, dataset source, methods, reproducible commands, validation, results, limitations, and references. Code and findings are my own work unless otherwise credited.

## Reproducibility and data ethics

Public data are linked by accession/DOI and reused under their applicable terms. No sensitive patient-level information, access tokens, restricted datasets, or large raw sequencing files will be committed. Findings are educational research exercises, not clinical diagnostic recommendations.
